# OnlineStore — Интернет-магазин

Полнофункциональный онлайн-магазин с веб-админкой для управления товарами, категориями и заказами.

## Быстрый старт

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```

Откройте http://localhost:3000

## Админ-панель

- URL: http://localhost:3000/admin
- Email: `admin@store.local`
- Пароль: `admin123`

## Возможности

### Витрина
- Каталог товаров с фильтрацией по категориям
- Страница товара
- Корзина (localStorage)
- Оформление заказа

### Админ-панель
- Дашборд со статистикой
- CRUD товаров (название, цена, остаток, фото, категория)
- Управление категориями
- Просмотр и изменение статуса заказов

## Стек

- Next.js 15 (App Router)
- Prisma + SQLite
- Tailwind CSS 4
- JWT-авторизация для админки
